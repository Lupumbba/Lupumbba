# Lupumbba

## AI 应用 · 金融研究 · Agent 工作流

我主要关注 AI 应用落地、金融数据研究和可复用的 Agent 工作流，习惯把一个想法整理成可以运行、验证和复用的项目。

## 技术方向

- **AI 应用**：大语言模型应用、多 Agent 协作、角色化分析、结构化输出和工具调用
- **金融研究**：美股新闻、行情监控、情绪分析、技术指标和可复现的量化回测
- **工程实践**：Python Web 应用、CLI、Streamlit、FastAPI、Flask、Docker 和项目文档
- **Agent 工具**：Codex Skill、知识库工作流、RAG、Obsidian 自动化和图像生成工作流

本主页中的项目分为三类：

- **个人原创或独立维护项目**：finance-ai-assistant、ai-wealth-debate、alphaear-finance、systematic-learning-engine、lulu-article-illustrations、photo-to-wonky-ink。
