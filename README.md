# Lupumbba

AI applications · quantitative research · agent workflows

I build practical tools that turn AI ideas into runnable products and research workflows.

My current focus:

- **AI applications** — LLM interfaces, multi-agent collaboration, structured debate, and tool-using workflows
- **Financial research** — US stock news, sentiment analysis, market monitoring, and reproducible backtesting
- **Reusable developer tools** — Codex Skills, CLI/Web interfaces, Docker workflows, and documentation that makes projects easy to run
